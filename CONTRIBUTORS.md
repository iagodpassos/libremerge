## Based on WinMerge

LibreMerge reuses the comparison engine of [WinMerge](https://winmerge.org/), so the people who built WinMerge are part of this project too. Among them:

* Dean Grimm: original developer
* Christian List: project lead
* Denis Bradford, Tim Gerundt, Marcel Gosselin, Gal Hammer, Takashi Sawanaka, Jochen Tucht: developers
* Laurent Ganier, Dennis Limm, Chris Mumford, Perry Rapp, Christian "Seier" Blackburn, Kimmo Varis: past developers

The full list, including the many WinMerge translators, is in WinMerge's [Contributors.txt](https://github.com/WinMerge/winmerge/blob/master/Docs/Users/Contributors.txt).

## External components used by LibreMerge

* WinMerge engine (GPL-2.0-or-later) (https://github.com/WinMerge/winmerge)
  * GNU diffutils, WinMerge's fork (GPL-2.0-or-later)
  * LibXDiff from git (LGPL-2.1-or-later) (https://github.com/git/git/tree/master/xdiff)
  * Crystal Edit syntax parsers (see "Parts of code by")
* WinIMerge, image comparison engine (GPL-2.0-or-later) (https://github.com/WinMerge/winimerge)
* Qt 6 (LGPL-3.0) (https://www.qt.io/)
* POCO (BSL-1.0) (https://pocoproject.org/)
* Boost (BSL-1.0) (https://www.boost.org/)
* ICU (Unicode-3.0) (https://icu.unicode.org/)
* libarchive (BSD-2-Clause) (https://www.libarchive.org/)
* xz / liblzma (0BSD) (https://tukaani.org/xz/)
* zstd (BSD-3-Clause) (https://facebook.github.io/zstd/)
* GoogleTest (BSD-3-Clause), for the engine test suite (https://github.com/google/googletest)
